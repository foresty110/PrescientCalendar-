# Demo Assets

루트 `README.md` 가 참조하는 데모 GIF·스크린샷 자리. 사용자가 직접 캡처해 같은 파일명으로 이 디렉터리에 넣으면 자동으로 표시된다.

## 캡처 체크리스트

| 파일 | 어떤 화면 | 권장 사양 |
|---|---|---|
| `demo.gif` | 한 호흡 시나리오 — 일정 생성 → 회고 → 실현 가능성 점수 색 변화 | 1280×800, 15fps, 30초 이내, 8MB 이하 |
| `signin.png` | `/signin` Google 로그인 화면 | 1280×800, PNG |
| `chat-create-event.png` | `/app` 우측 채팅에서 "내일 3시에 운동 1시간" 입력 직후, 좌측 캘린더에 chip 이 나타난 상태 | 1280×800, PNG |
| `chat-retrospect.png` | 회고 모드 대화 — `list_pending_retros` 결과 + 사용자 자연어 응답 + LLM 의 상태/시간 추론 | 1280×800, PNG |
| `feasibility.png` | 캘린더 chip 위에 색 점(초록/노랑/빨강/회색) 이 보이는 부분 + tooltip 펼친 모습 | 1280×800, PNG |

## 권장 캡처 도구

- macOS: **CleanShot X** (GIF) / `Cmd+Shift+5` (PNG, 영역 캡처)
- 또는 `ffmpeg -i input.mov -vf "fps=15,scale=1280:-1" demo.gif` 로 후처리

## 캡처 시 유의

- **시드 데이터 준비**: 실현 가능성 점수가 색 점으로 보이려면 과거 회고 데이터가 표본 5건 이상 필요. 회색 점만 잡히면 데모 임팩트가 약함. `pnpm db:seed` 의 시드 사용자로 로그인하거나, 며칠 미리 회고 입력
- **민감 정보**: 이메일·실명·내부 일정 제목은 캡처 전에 더미로 교체 또는 모자이크
- **다크/라이트**: 현재 UI 는 라이트 단일이므로 그대로 캡처
